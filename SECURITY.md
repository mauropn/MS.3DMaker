# Security policy

## Supported versions

MS3DMaker is pre-1.0. Security fixes are applied on a best-effort basis to the `main` branch.

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Prefer one of:

1. GitHub **Private vulnerability reporting** on https://github.com/mauropn/MS.3DMaker (if enabled on the repository)
2. A private contact method published by the founder later in this file

Please include:

- A description of the issue and impact
- Steps to reproduce or a proof of concept (if safe)
- Affected commit / version if known

You should receive an acknowledgement when the founder is available. Do not expect a fixed SLA while the project is in early development.

## Safe security practice for contributors

- Never commit API keys, tokens, passwords, or private keys
- Do not paste secrets into issues or PR logs
- Treat CI logs as public
