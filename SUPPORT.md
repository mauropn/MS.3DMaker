# Support

## How to get help

| Need | Where |
|------|--------|
| Bug report | GitHub Issues (bug template) |
| Feature idea | GitHub Issues (feature template) or Discussions |
| Build / setup | Check [docs/development/setup-guide.md](docs/development/setup-guide.md) first, then open an issue |
| Translations | [translations/CONTRIBUTING_TRANSLATIONS.md](translations/CONTRIBUTING_TRANSLATIONS.md) |
| Security | [SECURITY.md](SECURITY.md) only |

## What to expect

MS3DMaker is an early-stage, founder-maintained project. Responses may take time. There is no commercial support contract implied by this repository.

## Out of scope

- Reverse-engineering or obtaining proprietary Autodesk Fusion 360 internals
- Requests to violate dependency licenses or security policies
